# ProcessReview

A modern process intelligence dashboard for managing, reviewing, and analyzing organizational workflows.

## Features

- **Dashboard** — Real-time KPIs with animated counters, sparklines, and trend indicators
- **Process Library** — Browse, create, and manage all processes with progress tracking
- **Review Board** — Kanban-style workflow for pending, in-review, approved, and rejected items
- **Analytics** — Cycle time trends, department breakdowns, reviewer workload, and throughput charts
- **Team Management** — Team member profiles with review stats and availability status
- **Dark Mode** — Full light/dark theme support with system preference detection
- **Responsive** — Works across desktop, tablet, and mobile viewports

## Tech Stack

- Pure HTML5, CSS3, and vanilla JavaScript (no build step, no dependencies)
- Custom canvas-based charting engine (bar, line, donut, horizontal bar, stacked bar, sparkline)
- CSS custom properties for theming
- CSS Grid and Flexbox for layout

## Getting Started

Open `index.html` in any modern browser. No server or build tools required.
